# BRCode Android

Native Kotlin + Jetpack Compose application.

## Integrations

- AdMob is wired with the official Google test application ID by default. Production ID is supplied through the Gradle property ADMOB_APP_ID.
- Firebase Analytics dependency is prepared. The Firebase project configuration file (google-services.json) must be supplied from the owner's Firebase console before enabling the Google Services Gradle plugin.
- Release signing credentials must be provided through GitHub Actions secrets; no keystore is committed.

## Build

Open android/ in Android Studio or run the Gradle wrapper once it is generated by Android Studio.

For a production AdMob build:
./gradlew assembleRelease -PADMOB_APP_ID=YOUR_ADMOB_APP_ID

Do not commit real Firebase configuration or signing credentials unless their exposure is explicitly intended.
