# BRCode Web

Static web application for GitHub Pages.

This directory is intentionally separated from the Android application.

Planned layers:

- `public/` — static assets and SEO files.
- `src/components/` — reusable UI.
- `src/layouts/` — page layouts.
- `src/pages/` — routes/pages.
- `src/qr/` — QR domain logic.
- `src/styles/` — design system and responsive styles.
- `src/config/` — public configuration.
